# CSS Overview Static Website

## Project Description

This project is a simple static website created using HTML and CSS. The website showcases childhood hobbies and favourite toys through structured content, images, and custom styling.

The purpose of this project is to demonstrate fundamental web development concepts including:

- HTML page structure
- CSS styling
- Image integration
- Internal page navigation
- Website deployment using GitHub Pages

## Features

- Responsive page layout
- Custom CSS styling
- Styled headings and sections
- Embedded images
- Back-to-top navigation link
- Hosted using GitHub Pages

## Technologies Used

- HTML5
- CSS3
- GitHub Pages

## Website Sections

### Hobbies
- Reading
- Outdoor Play

### Toys
- LEGO
- Toy Cars

Each section includes descriptive content and supporting images.
